# Human review and merge

Pull requests into `main` require an independent approval, the required `Repository quality` check on the current commit, and resolved conversations. Auto-merge remains disabled.

@Lancelot-sys25 is the primary reviewer and merge coordinator. @Hungle2910 remains the repository owner and admin backup, including for pull requests authored by @Lancelot-sys25. Authors cannot approve their own pull requests. A reviewer checks behavior, authorization, data integrity, failure cases, tests and release evidence before approving. Merge only after GitHub reports that all branch protection requirements pass.

Code review tools may be evaluated separately, but no AI reviewer is installed or required by this policy. The reviewer does not treat a successful CI check as proof of product behavior or AWS deployment.
