# M3-07 security regression evidence (partial)

On 2026-11-17, `Backend/tools/m303_smoke.ps1` passed against isolated local SQL Server database `AiExamBankM307_20261117`. It verified Teacher decision `403`, stale decision `409`, concurrent decisions `200/409`, a reviewer with a revoked role getting `403` on both the queue and a direct decision request in the same signed-in session, and a revision author with a newly granted DepartmentHead role still getting `403` on direct self-review. Another authorized reviewer could approve that revision. These are direct HTTP results, not only UI checks.

The tracked-tree scan found no AWS access key or private-key block outside test fixture strings. `Frontend/.env.example` is a placeholder, not a deployed secret. Dependency advisory checks found one moderate Next.js advisory, [GHSA-mfr8-8qww-v76h](https://github.com/advisories/GHSA-mfr8-8qww-v76h), affecting the previous 16.4.2 version under a specific `use cache`/`unstable_cache` combination. No call to either API was found under `Frontend/src`; this is a vulnerable dependency version, not a confirmed exploit in this app. Next.js and its matching ESLint config were updated to 16.4.6. The production dependency audit now reports zero vulnerabilities, and the frontend production build (including TypeScript) passes.

The full M3-07 gate still needs a fresh scan and direct API matrix on the integrated M1/M4/M5 release candidate, plus staging IAM, source/citation, job and exam scope checks with M2. Do not mark this week's acceptance complete from the local review and role tests alone.
